# data/raw — 원본

**zip에 실물이 들어있다. 수동으로 복사할 것 없다.**
압축 풀고 `python src/etl/ingest.py` 하면 끝.

---

## 명명 규칙

```
{기관}_{데이터}_{범위}_{기준일}.{확장자}
```

| 자리 | 규칙 | 예 |
|---|---|---|
| 기관 | 소문자 약칭 | `juso` `ngii` `its` `sbiz` `safety` `nsdi` |
| 데이터 | 소문자 스네이크 | `road_geom` `nodelink` `cctv` `parking_enforce` |
| 범위 | 소문자 약칭 | `jngj`(전남광주) `gwangju` `dongu` `kr`(전국) `gj037`(도엽) |
| 기준일 | `YYYYMMDD` | 데이터 기준일. 다운로드일 아님 |
| 확장자 | 아래 3종. 그 외 금지 |

## 확장자

| 확장자 | 쓰는 곳 |
|---|---|
| `.zip` | SHP 세트 · 다중 파일 묶음 |
| `.csv` | **모든 표.** json 으로 와도 normalize_raw.py 가 변환한다 |
| `.tif` | 래스터(정사영상). 같은 이름의 `.xml` 메타데이터와 짝 |

**표는 csv 로 통일한다.** 같은 데이터셋이 csv 였다가 json 으로 내려오는 일이 흔한데,
그때마다 `ingest.py` 의 `kind` 를 바꾸면 파이프라인이 흔들린다.
소방용수시설이 실제로 그랬다(2026-08-11). 33.2MB json → 14.3MB csv 로 줄기도 한다.

**원본을 재압축하지 않는다.** `.tif` 를 `.zip` 으로 감싸면 `ortho.py` 가 매번 풀어야 하고
1.3GB 를 두 번 쓰게 된다. sha256 재현성도 깨진다.

**폴더명 = 기관명이다.** `juso/juso_*`, `ngii/ngii_*` 처럼 짝이 맞아야 한다.
`misc/` 같은 잡폴더를 만들지 말 것. 기관을 특정할 수 없으면 발주처를 쓴다.

| 기관 | 폴더 |
|---|---|
| 도로명주소 | `juso` |
| 국토지리정보원 | `ngii` |
| 국가교통정보센터 | `its` |
| 소상공인시장진흥공단 | `sbiz` |
| 소방청·행안부 안전 | `safety` |
| 광주광역시·산하기관 | `gjcity` |
| 국토정보플랫폼(공간정보) | `nsdi` |

**규칙 3개**

1. **파일명에 한글·공백·괄호·대문자 금지.** cp949/UTF-8 인코딩 사고와 셸 이스케이프 지옥의 원인이다. 실제로 원본이 `상가__40_상권__41_정보`처럼 깨져서 왔다.
2. **모든 CSV는 UTF-8.** 원본이 cp949였던 것도 전부 변환했다. 팀원 5명이 파일마다 인코딩을 다르게 열어야 하는 비용이 원본 바이트 보존보다 크다.
3. **파일명을 바꾸지 마라.** `sources.yaml`의 `file:` 경로와 1:1로 묶여 있다.

⚠ zip 안의 SHP는 `.dbf`가 여전히 cp949인 것이 있다(`juso`). 원본 구조라 건드리지 않았고, `sources.yaml`의 `encoding:`이 항목별로 선언한다.

## 안 들어있는 것

**항공정사영상 4장 (1.3GB)** — 용량 때문에 제외. Phase 3-A까지 안 쓴다(우선순위 4위).
로컬에 이미 있고 국토정보플랫폼(map.ngii.go.kr)에서 재취득 가능.

| 파일 | 크기(px) | SHA-256(앞16) | 도엽 |
|---|---|---|---|
| `_B060_정사영상_2025_35616037.tif` | 9516 × 11496 | `afe2cbb4bcd15153` | 북서 |
| `_B060_정사영상_2025_35616038.tif` | 9516 × 11508 | `d83eec9e4da02b1b` | 북동 |
| `_B060_정사영상_2025_35616047.tif` | 9516 × 11508 | `c0d4850dfdbe197e` | 남서 |
| `_B060_정사영상_2025_35616048.tif` | 9528 × 11496 | `074d2d29a73dcaea` | 남동 |

넣을 때 규칙에 맞게 이름을 바꿔라 → `ngii_ortho_gj037_20251231.tif` 형태.

⚠ GeoTIFF 아님. 지오태그·`.tfw` 없고 메타 XML에도 도곽좌표가 없다.
복원 규칙과 도엽별 X0/Y0는 `docs/마스터_문서.md` §10 참조
(**EPSG:5186** — 수치지도 5179와 다르다).
