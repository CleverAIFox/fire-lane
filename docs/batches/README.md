# 지시문의 요지 — `docs/batches/`

DECISIONS 는 「지시문」을 가리킨다. 지시문 = 사용자가 에이전트(Claude Code)에게 준 작업 지시다.
감사(2026-10-24)는 「지시문이 저장소에 없다」를 지적했다. **이 저장소는 지시문 원문을 넣지 않는다.**
사람이 그렇게 정했고(DECISIONS §568-2), **지시문의 요지는 DECISIONS 의 해당 절이 든다.**
이 디렉터리는 「어느 판의 요지가 어느 절에 있는가」를 가리키는 색인이다.

## 규약

1. **원문을 기다리지 않는다.** 「요지만 있음」이 정상 상태다. 사람이 원문을 넣어 주기를 바라는 구조가 아니다.
2. **DECISIONS 가 「지시문」을 인용하면 이 색인을 가리킨다** — 꼴은 `(지시문 docs/batches/Zm19.md)` 다.
   요지만 있는 판은 `(지시문 요지 · Zm19)` 로도 적는다. 파일도 요지 표시도 없는 인용은
   `tests/test_batches_index.py` 의 래칫이 센다 — 새로 늘면 운다.
3. **이 표가 정본이다.** 판마다 요지가 있는 절을 적는다. 절이 없으면 없다고 적는다(`절 없음`).
   표의 절 번호가 DECISIONS 에 실재하는지 시험이 본다.
4. 사람이 원문을 넣기로 마음을 바꾸면 `Zm<번호>.md` 를 이 디렉터리에 두고 표의 마지막 칸에 적는다.
   그때까지 파일은 없는 것이 맞다.
