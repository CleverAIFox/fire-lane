# DECISIONS — 왜 그렇게 고쳤나

MASTER 는 **지금 어떤가**를 적는다. 이 파일은 **왜 그렇게 됐나**를 적는다.
둘을 한 문서에 섞으면 MASTER 가 이력으로 부풀어 아무도 안 읽는다.

## 이 파일이 생긴 이유

2026-08-17~18 에 `tools/` 로 일회성 패처 9개가 들어왔다. 전부 소스나 문서를
문자열 치환으로 고치는 스크립트였고, 적용된 뒤에는 no-op 이었으며, 둘은
앵커가 깨져 재실행조차 불가능했다. 코드로는 죽었지만 **docstring 이 사고
원인의 유일한 기록**이었다. 그래서 근거만 여기로 옮기고 스크립트는 지웠다.

앞으로 일회성 작업은 돌리고 지운다. 남길 값이 있으면 여기에 적는다.
`tests/test_guards.py::test_no_dated_scripts_in_tools` 가 이 규칙을 강제한다.

## 2026-08-18 · `docnum_check` 가 옛 숫자 45곳을 놓친 이유

이 도구는 "맞는 숫자가 **있는가**"만 봤다. 문자열 포함 검사라, 문서에
1101 과 1087 이 **둘 다** 있으면 통과한다. §2 표만 갱신하고 나머지를
안 고쳐도 초록불이었다. 실제로 그랬다 — MASTER 에 `1,087` 10곳,
`1,093` 1곳, `396` 3곳, `191` 2곳, PLAN 에 `1,087` 1곳 · `396` 2곳.

    있는지 보는 검사   추가 누락에 강하다
    없는지 보는 검사   삭제 누락에 강하다

둘 다 있어야 한다. `RETIRED` 목록을 붙였다. 산출값이 바뀌면 옛 값을 거기
한 줄 추가하는 것이 이 도구의 유지보수 전부다.

★ 현재형 영역에서 옛 숫자를 **의도적으로** 인용하는 곳이 있다(§2 의
  "1093 · 1091 은 무효다" 블록). 그 줄에 `<!--stale-ok-->` 를 붙인다.
  마커를 다는 일 자체가 "이 옛 숫자는 실수가 아니다"를 문서에 남기는
  것이라, 억제 주석이 곧 기록이 된다.

필드표 대조도 붙였다. MASTER §11 이 `n_sample` 등 7개를 웹 필드로 적어놨는데
`publish_web.py` 는 내보내지 않는다. UI 담당이 그 표를 보고 코드를 짜면
`undefined` 가 나온다. 반대로 `width_verified` 등 3개는 산출물에만 있었다.

## 2026-08-18 · `width_max_m` 결손이 판정을 관대한 쪽으로 기울인다

UI 팝업에서 폭 1.57m 구간의 "벽 사이 폭"이 `—` 로 뜬 것이 실마리였다.
MASTER §11 은 그것을 "큰 도로는 건물이 40m 밖이라"로 설명했는데,
1.57m 골목에 건물이 40m 밖일 수는 없다. **설명이 사례를 안 덮으면
설명이 틀린 것이다.**

    결손 496 / 1,101 (45%) · 도로 폭대별로 고르게 퍼져 있다

`seg/geom.py::verdict()` 가 `blocked` 를 `wmax` 로만 낸다.

    if wmax is not None and wmax < TRUCK:  return "blocked"
    ...
    if wmin is not None:                    return "needs_cv"

`wmax` 가 없으면 blocked 로 갈 길이 없다. 도로 폭 3.0m 미만 구간에서
갈리는 정도가 이렇다.

## 2026-08-18 · `blocked` 를 두 근거 합치로 확정한다 (63 → 159)

`seg/geom.py::verdict()` 는 `blocked` 를 `wmax` 로만 낸다.
