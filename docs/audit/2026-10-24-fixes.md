## 6. 하지 말 것

- git 이력 재작성(filter-repo·rebase·force push)을 하지 않는다. 사용자 결정이다.
- 골든 재잠금(`golden.py lock`), `baseline.py freeze`, `docseal stamp` 를 하지 않는다.
- `seg/params.py` 임계값과 판정 규칙을 바꾸지 않는다. 판정을 움직이는 수정(N5·N6·1-3)은 사용자 결정 뒤에 한다.
- DECISIONS 의 결정 기록을 지우지 않는다. 문체 요지화만 하고, 그 예외를 새 절에 남긴다. 숫자 정정은 기존 절을 고치지 않고 새 절로 적는다.
- 시드 19980711, 학교명, CODEOWNERS 아이디, SECURITY 메일을 사용자 결정 없이 바꾸지 않는다.
- `Co-Authored-By` 서명을 지우거나 막지 않는다.
- 비속어·채팅 원문을 시험 자료나 검사기 설명에 새로 넣지 않는다. 검사기 시험은 합성 문장으로 쓴다.
- 토큰·키·계정 번호 같은 비밀 값을 문서·커밋 메시지·시험에 옮기지 않는다.
