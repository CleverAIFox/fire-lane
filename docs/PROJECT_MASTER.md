## 3. 도로폭 소스 — 확정

### 결론

| 역할 | 소스 | 구간 |
|---|---|---|
| **주 소스** | 수치지도 도로경계면 `NF_A_A01000` (1:5,000) | 207 |
| **폴백** | 실폭도로 `TL_SPRD_RW` | 14 |
| 결측 | seg_2157 (중앙로) | 1 |
| | **커버리지** | **221 / 222** |

두 소스는 경쟁이 아니라 **상보 관계**다. 수치지도는 1:5,000 정밀도로 넓은 길을 정확히 그리지만, **보행자 통로급 최협소 골목(road_bt 1~3m)을 도로면으로 아예 그리지 않는다.** 결측 15구간을 실폭도로가 14개 메웠다.

```
width_m     = 중심선 2m 간격 샘플의 중앙값   (표시용)
width_min_m = 같은 샘플의 최솟값             (판정용) ★
width_p25_m = 하위 25%                       (예비)
```

**판정은 최솟값을 쓴다.** 교차로에서 도로면이 사방으로 퍼져 거리변환 값이 튀므로(최대 39m 관측) 최대값은 쓰지 않는다. 소방차는 어차피 가장 좁은 병목을 통과하지 못한다.

| 산출물 | `data/processed/dongmyeong_ortho.tif` (5906×5677px, 1476×1419m) |

### 지오레퍼런싱 복원 (배포 파일에 좌표 정보 없음)

배포된 `.tif`는 GeoTIFF가 아니며 `.tfw`도 제공되지 않는다. 메타데이터 XML에도 도곽 좌표가 없다. 아래 절차로 복원했다.

1. **도곽 규칙 확정** — 함께 받은 수치지도(국가기본공간정보)의 bounds를 경위도로 역산한 결과 도곽이 정확히 **1′30″ × 1′30″ 격자**임을 확인 (오차 0.5″ 이내).
2. **여백 확정** — 정사영상 = 도곽 + 사방 50m. 이 모델이 4개 도엽의 영상 **폭을 전부 1픽셀 이내로 예측**.
3. **육안 검증** — 수치지도 도로경계선을 영상에 겹쳐 골목과 일치함을 확인.

```
도엽       X0(좌상단)      Y0(좌상단)
037      190837.82      286564.39
038      193115.87      286562.37
047      190835.04      283790.80
048      193113.78      283788.78
해상도 0.25 / 좌표계 EPSG:5186
```

잔여 절대위치 오차 ±1~2m. **전역 평행이동이므로 폭 측정에는 영향 없음.**

### 폭 추출 시도 — 실패 (기록)

정사영상에서 직접 폭을 뽑으려 두 가지를 시도했고 **둘 다 실패**했다.

1. **색 임계값** (무채색 + 아스팔트 밝기대) — 마스크가 공터·건물 지붕까지 번짐
2. **시드 기반 영역확장** (수치지도 도로면을 시드로) — 화면의 92.9%가 도로로 판정

원인: 시드로 쓴 도로면 안에 주차 차량·그림자·노면표시가 포함되어 색 분포 표준편차가 밝기 ±54.6에 달한다. 색 정보만으로는 분리 불가.

**진짜 세그멘테이션 모델(SAM 등)이 필요하다.** 다만 우선순위는 낮다 — GSD 0.25m 기준 이론 한계가 ±0.5m로, 이미 확보한 수치지도(1:5,000)보다 나빠진다. 12cm급 도시지역 영상을 확보할 수 있다면 재검토.

**정사영상의 현재 값어치는 폭 측정이 아니라 검증과 시각자료다.** 도곽 원점 확정 시 벡터 오버레이 검증에 실제로 사용되었다.

> 참고: 상호상관(cross-correlation) 정합도 시도했으나 z-score 2.6~4.4로 수렴하지 않았고 결과가 틀렸다. 육안 오버레이로 기각. 약한 통계량을 신뢰하지 말 것.

## 5. 노상 점유 차량 — 용어와 법적 근거

**"불법주정차"라는 용어를 쓰지 않는다.**

- 골목 노상 주차는 주차금지 표지가 없으면 **대체로 적법**하다. 소화전 5m, 교차로 모퉁이 5m, 횡단보도, 어린이보호구역 등만 금지.
- **위법 여부는 우리 판정과 무관하다.** 소방차를 막는 것은 그 차가 적법하든 아니든 동일하게 점유하는 물리적 폭이다.
- 소방기본법상 소방활동에 방해되는 주정차 차량은 **적법 주차라도 제거·이동** 대상이다. 위법성 판정 자체가 불필요하다. *(조항 원문 확인 필요 — C-08)*

용어 대응: 불법주정차 → **노상 점유 차량** / 점유 폭 / 단속 이력(= 상습 점유 구간의 대리지표)

## 7. 판정 로직

### 1차 분류 (정적, 전수 222구간)

```
width_m >= 12  → BLUE   통행 여유       (9)
width_m <  2   → RED    통행 불가       (20)
그 외          → CANDIDATE              (193)
   ├ CCTV 있음 → YELLOW  실시간 판정 대상 (136)
   └ CCTV 없음 → GRAY    관측 불가        (57)
```

임계값 근처(2m, 12m)를 제외하면 ±1~2m 오차가 분류를 바꾸지 않는다. **1차 분류에는 현재 데이터로 충분하다.**

### 2차 판정 (실시간, YELLOW 대상)

```
통행폭 = 영상에서 측정한 연석~차량 최소 간격
판정   = 통행폭 vs 소방차 필요폭(2.5m + 여유)
```

- 차량 폭은 **사이드미러 바깥 끝** 기준 (접힘/펼침 무관하게 타이어보다 돌출)
- 구간 대표값은 **최솟값** (가장 좁은 병목)
- 차량–벽 이격거리는 **죽은 공간**으로 처리 *(P-17, 미확정)*

### 인도 포함 문제 — 해소됨

동명동 도로의 68%가 폭 5m 미만이라 인도가 물리적으로 존재할 수 없다. 인도가 있을 수 있는 5~8m 구간 43개도, 인도 2m를 잘못 포함해도 판정이 뒤집히지 않는다(잔여 폭이 여전히 소방차 통과 가능). **1차 분류에서 무시해도 되는 오차.**

## 8. 캘리브레이션 / 호모그래피

### 개념 정리 (팀 공유용)

호모그래피 H는 **평면↔평면 3×3 변환** 하나의 개념이다. 다만 평면 쌍마다 다른 H가 존재한다.
- 지면 ↔ 이미지 : **우리가 필요한 것**
- 번호판면 ↔ 이미지 : 수직면이라 지면 폭 계산에 쓸 수 없음

**도로폭 데이터로는 대응점 자동화가 안 된다.** 폭을 쓰려면 화면에서 연석 두 점을 먼저 찍어야 하는데, 그게 곧 수동 클릭이다. 또한 폭은 스칼라 1개(=2점)인데 H는 8자유도(=4점)를 요구한다.

### 두 노선 (택일)

| | 입력 | 산출 |
|---|---|---|
| **A. 호모그래피** | 대응점 4쌍 (수동) | H → 화면 임의 두 점 거리 |
| **B. 단안 3D 재구성** | 카메라 높이 1개 | 지면 평면 → 3D 거리 |

B는 카메라 1대당 숫자 1개만 필요해 전수 확장이 가능하다. 촬영을 스마트폰 삼각대로 하기로 했으므로(결정 02) **높이는 측정값이 아니라 설정값**이다.

### 자동 대응점 후보 — 답사에서 발견

현장 사진에 **보도블록 격자**(표준 300×300mm)가 도로 전면에 깔려 있고 **맨홀 뚜껑**(지면 위 원 → 영상에서 타원)도 다수 확인됐다. 지면 위 규격 평면 패턴이므로 대응점 자동 검출에 쓸 수 있다. 황색 실선은 폭 10~15cm로 너무 얇아 부적합.

### 경로탐색 가중치 (재설계안)

```
cost = length_m × (1 + α·판정페널티 + β·점유위험도)

length_m    지오메트리 재계산값 (road_lt 사용 금지)
판정페널티  RED=∞ / YELLOW=실측기반 / BLUE=0 / GRAY=0.5
점유위험도  단속밀도(건/100m/년) 정규화
```

덧셈이 아니라 **곱셈**이어야 한다. 덧셈이면 짧은 위험구간과 긴 안전구간의 비교가 왜곡된다.

## 12. 작업 원칙 — 2026-08-06 사고에서

1. **모든 수치는 두 가지 방법으로 계산하고 불일치를 먼저 본다.** 수직선법 단독 사용으로 210개 구간의 폭이 절반으로 계산됐고, 현장 답사에서야 발견됐다.
2. **물리적으로 말이 안 되는 값은 데이터가 아니라 코드를 의심한다.** "골목 폭 1.3m"가 다수 나왔을 때 즉시 멈췄어야 했다.
3. **약한 통계량을 신뢰하지 않는다.** z-score 3.5의 상관 피크는 틀린 답이었고 육안 확인으로 기각됐다.
4. **실측은 유일한 정답지다.** 소스 선택은 실측 대조로만 결정한다.
