## A. 팩트체크 — 발표에서 찔릴 순서

### A-0. ★ 최우선 발견 (2026-08-07)

**소방청 공식 기준을 확인했다. 우리 임계값이 우연히 맞았고, "100m 규정"의 정체도 밝혀졌다.**

> 소방청 「2025년 화재현장 골든타임 확보 종합대책」 — 진입불가지역 / 진입곤란지역 구분
>
> - **진입불가**: 폭 **2m 이하** 도로, 또는 이동 불가 장애물로 진입 불가한 **구간이 100m 이상**인 장소 (중형펌프차 폭 **2.5m** 기준)
> - **진입곤란**: 폭 **3m 이상** 도로 중 장애물로 진입곤란한 **구간이 100m 이상**인 지역, 및 **상습주차(장애물)로 상시 진입·활동에 장애를 초래하는 장소** (중형펌프차 폭 2.5m 기준)

| 항목 | 우리 설정 | 공식 기준 | 판정 |
|---|---|---|---|
| FIXED_BLOCK 임계값 | < 2.0m | 진입불가 = 2m 이하 | **일치** |
| 판정 기준 차량 폭 | 2.5m | 중형펌프차 2.5m | **일치** |
| "100m 규정"(P-18) | TMAP 배제 근거로 사용 | **구간 길이 조건**이었음 | **오해. 정정 필요** |
| 상습주차 장애 | 우리 프로젝트의 대상 | **공식 정의에 이미 포함** | 정책 정합성 근거 |

**해야 할 일**
1. **1차 출처 확보** — 위 내용은 커뮤니티 게시판의 소방청 답변 인용본이다. 소방청 원문(종합대책 공문 또는 보도자료)을 확보해야 발표 인용 가능. 동부소방서 인터뷰 시 직접 요청할 것.
2. **§4 임계값 문구 수정** — "공식 규정 인용 아니고 팀 자체 추정치"를 **"소방청 진입불가 기준과 일치"**로 격상.
3. **12m(FIXED_PASS) 임계값은 여전히 자체 추정치** — 공식 기준에 상한 개념이 없음. 이건 계속 추정치로 명시.
4. **3m 기준 도입 검토** — 공식 진입곤란 기준이 3m다. 현재 우리 CANDIDATE 하한이 2m인데, 2~3m 구간을 별도 등급으로 뺄지 논의.
5. ⚠ **차별성 재정의** — 소방청이 이미 진입불가/곤란 지역을 지정·관리 중이다. "이런 시스템이 없다"는 주장은 **틀렸다.** 정정된 포지셔닝:
   > 지정은 **수동 전수조사 기반이고 정적**이다. 우리는 **자동 산출 + 실시간 갱신**이다.
   기존 제도를 부정하는 게 아니라 **그 제도를 자동화·실시간화**한다는 프레임이 훨씬 강하고 방어 가능하다.
